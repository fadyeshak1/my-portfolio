About the Project

YumUp is a Flutter mobile application built to solve a simple everyday problem: users waste time deciding what to eat because restaurant information is scattered and there's no personalized way to compare options. YumUp brings restaurant browsing, meal details, ratings, and personalized recommendations into one clean, modern app.

The app is built with Clean Architecture and the Bloc/Cubit pattern for scalable, testable state management, and uses Supabase as a cloud backend for authentication, realtime database, and storage — handling all data persistence and user management.

Users can browse restaurants by category or search, view full meal details with photos and ingredients, rate and review meals, save their favorites, revisit their order history, and submit suggestions for new restaurants — all wrapped in a responsive, elegant dark-themed UI.

Smart Discovery

Browse restaurants and meals by category, cuisine, or popularity, with a powerful search bar for fast food discovery.

Ratings & Reviews

Users can rate meals and submit detailed reviews to help the community make smarter dining decisions.

Clean Architecture

Built with Bloc/Cubit state management and a repository layer that decouples business logic from the Supabase backend.
